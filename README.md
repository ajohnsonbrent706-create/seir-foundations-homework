# seir-foundations-homework

TheoWAF SEIR Foundations — Homework & Labs

Repository Overview

This repository serves as a centralized collection of coursework, technical assignments, hands-on laboratories, and supporting documentation completed throughout the TheoWAF SEIR Foundations Program.

The program focuses on developing foundational knowledge and practical experience in cloud computing, IT infrastructure, Linux system administration, networking, version control, and DevOps principles.

Each assignment is designed to reinforce technical concepts through practical implementation, troubleshooting, repetition, and documentation while developing the skills necessary for a career in Cloud Engineering and Infrastructure Operations.

Learning Objectives

The primary objectives of this repository include:

Cloud Computing: Develop practical knowledge of Amazon Web Services (AWS), including cloud infrastructure provisioning, configuration, management, and resource cleanup.

Linux Administration: Strengthen command-line proficiency through system navigation, file management, software installation, and remote server administration.

Git & GitHub: Apply version control practices, including repository management, branching, commits, pushes, and collaborative workflows.

Networking & Security: Understand SSH connectivity, public IP addressing, security groups, inbound traffic rules, and secure cloud access.

Application Deployment: Configure cloud-hosted environments, install dependencies, deploy applications, and verify API functionality.

Troubleshooting: Identify technical issues, implement corrective actions, and document resolutions.

Technical Documentation: Maintain organized README files, deployment evidence, screenshots, and detailed laboratory reports.

Documentation Standards

Laboratory submissions may include:

Assignment objectives and implementation summaries.

Configuration details and terminal commands.

Screenshots demonstrating successful deployment and functionality.

Errors encountered and troubleshooting procedures.

Lessons learned and opportunities for improvement.

Resource cleanup and completion verification.

Professional Development

This repository also documents continued progress toward developing the technical competencies required for entry-level Cloud Engineering, Cloud Operations, and IT Infrastructure roles.

The coursework supports ongoing preparation for AWS certifications, including the AWS Certified Cloud Practitioner (CLF-C02) and AWS Certified Solutions Architect – Associate (SAA-C03).

Repository Purpose

The purpose of this repository is to demonstrate consistent technical growth, hands-on problem-solving abilities, professional documentation practices, and practical application of cloud infrastructure concepts throughout the TheoWAF SEIR Foundations Program.

As additional modules and laboratory assignments are completed, this repository will continue to expand as a documented record of technical development.
